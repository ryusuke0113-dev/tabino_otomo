## 余裕があれば足すこと（時間が余ったら上から足す）

- 地図にピンを立てて表示する: 地図を表示するための道具の使い方を新しく覚える必要があり、一覧で十分にデモできるため。
- 生成 AI で、お店ごとのひとこと紹介やおすすめを作る: API キーと料金の準備が必要で、最小形がなくても成り立つため。
- LINE Bot にして、近くに来たら知らせる: 前回の反論4の「自分から調べない人」に一番効く機能です。ただ、LINE の登録やインターネット上に公開する作業が必要で、4日間で学んだ範囲を大きく超えるため外しました。
